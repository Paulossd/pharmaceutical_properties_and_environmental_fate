# Pharmaceutical compounds at the surface water–groundwater interface: a systematic evidence synthesis of their properties and fate at the hyporheic zone

Reproducible analysis pipeline and supporting materials for the systematic evidence synthesis by **Tufoni & Nunes**.

## Overview

This repository contains the R analysis pipeline and supporting documentation for the systematic evidence synthesis of pharmaceutical physicochemical properties and environmental fate at the surface water–groundwater interface, with particular emphasis on the hyporheic zone.

The workflow is implemented as a **single annotated R script** that reads the compiled input workbook `SM_2.xlsx` and applies the predefined harmonisation, censoring, aggregation, sensitivity-analysis, and statistical procedures described in Sections 2.3–2.8 of the manuscript.

The pipeline generates the derived analytical tables and figures reported in the manuscript and Supplementary Material, while retaining provenance and audit information for the underlying records.

The workflow includes:

* harmonisation of raw physicochemical and environmental-fate records using predefined rules, with cell-level audit trails;
* dataset census and assessment of censored observations;
* sensitivity analysis for below-limit substitution and censored-data concentration estimation;
* descriptive statistics using record-weighted (**HAR**) and compound-weighted (**AGG**) aggregation;
* compound-level property–persistence analyses;
* persistence, mobility, and bioaccumulation screening and associated sensitivity analyses;
* provenance-resolved half-life lineage and ratio analyses; and
* generation of boxplots and synthesis figures.

**Scope:** 48 pharmaceutical compounds across 15 therapeutic classes, following PRISMA 2020.

## Methodological summary

The pipeline applies the predefined harmonisation and censoring rules described in Section 2.3 of the manuscript.

Non-standard reported values are converted to analysis-ready numeric representations according to the declared rules. These include detections, reported ranges, approximate values, and censored observations.

Left-censored concentration observations are retained as censored observations for the relevant statistical analyses rather than being treated as detections.

The four concentration variables:

```text
C_SW
C_HZ
C_SED
C_GW
```

are analysed using censored-data methods. Kaplan–Meier estimates are used as the primary estimator, with Turnbull and DL/2 approaches used for sensitivity assessment and cross-checking where applicable.

For non-detect observations for which no explicit reporting limit is available, the lowest detected concentration for the corresponding variable is used as the censoring limit. A common detection limit across matrices is not imposed.

Physicochemical properties and half-lives are summarised according to the predefined harmonisation and quality-control rules. Observations considered physically implausible under the declared criteria are excluded.

Results are reported using two aggregation schemes:

* **HAR (record-weighted):** each eligible analytical record contributes to the summary;
* **AGG (compound-weighted):** compound-level summaries are calculated first, after which compounds contribute equally to the overall summary.

Class-level and compound-level concentration estimates are calculated only when the predefined minimum-data criteria are satisfied.

Quantiles are calculated using the **type-7 quantile estimator** implemented in R.

The complete harmonisation, censoring, aggregation, screening, and statistical procedures are defined in the manuscript and associated Supplementary Material.

## Reproducibility and provenance

The repository is designed to provide an auditable computational workflow from the compiled input data to the reported analytical outputs.

Key reproducibility features include:

* **Single analysis script:** the main workflow is implemented in one annotated R script.
* **Explicit input structure:** the required workbook and input-sheet structure are documented.
* **Cell-level auditability:** harmonisation decisions are recorded in the corresponding audit tables.
* **Source provenance:** source, reference, study-design, and data-origin information are retained throughout the workflow.
* **Half-life provenance:** laboratory, field, and database-derived estimates are distinguished where information is available.
* **Derived outputs:** harmonised datasets, statistical summaries, sensitivity analyses, and figures are generated programmatically.
* **Predefined rules:** analytical decisions are implemented according to the rules described in the manuscript.
* **PRISMA information:** study-identification and screening counts originate from the systematic-review screening process and are documented separately; they are not reconstructed from the quantitative input workbook.

The numerical results reported in the manuscript can be reproduced by executing the published pipeline with the corresponding `SM_2.xlsx` input workbook and the documented computational environment.
